# Frontend TrabajoYa
Flutter/Dart. API local, assets de configuración, cuentas sintéticas e instrucciones: [README principal](../README.md).

El frontend incluye modos cliente/proveedor, catálogo, solicitud/contratación y mensajería. La ejecución Flutter, pruebas y build no se comprobaron porque falta el SDK. `preparar-demo.ps1` crea ambos assets .env locales y rechaza sobrescribir archivos existentes. No se distribuyen configuraciones Firebase de producción: no se puede asumir que todas las funciones de notificaciones operen en esta copia.
